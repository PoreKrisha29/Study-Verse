StudyVerse
Your All-in-One AI-Powered Study Platform
🌐 Web App + PWA 🤖 Gemini AI 🎙️ Voice Controlled 🎮 Gamified 🔴 Live Streaming
Feature Summary  |  Built with Flask · PostgreSQL · Socket.IO · Google AI
StudyVerse is a full-stack web application designed to make studying smarter, more social, and actually enjoyable. It combines a Pomodoro focus timer, AI-powered tutoring, competitive quiz battles, real-time group study streams, task management, a habit tracker, and a gamified XP reward system — all controlled by a natural-language voice assistant called Verse. Built as a Progressive Web App (PWA), it works offline and can be installed on any device like a native app.
Core Features
🏠
Dashboard

Central hub showing daily XP progress, streak count, pending tasks, upcoming calendar events, habit status, and a real-time online/offline friend indicator. Also displays personalized AI study plan suggestions.

⏱️
Focus Mode (Pomodoro)

Customizable Pomodoro timer with Focus, Short Break, and Stopwatch modes. Features include:

  • Custom duration (up to 180 min)
  • Session goals with progress tracking
  • Brain dump notepad during sessions
  • Go-Live button to stream while studying
  • XP awarded per completed focus session
✅
Task Manager

Full-featured to-do system with priority levels (High / Medium / Low), due dates, due times, and email reminders. Supports:

  • Batch task import via AI plan
  • Undo last-deleted task
  • Category tagging
  • XP reward on task completion
  • Automated email notifications when tasks are due
🎯
Start Quiz
AI

AI-generated multiple-choice quizzes powered by Gemini. Choose question count (5/10/15/20) and difficulty (Easy / Medium / Hard). Questions cover a wide range of study topics. Correct answers earn XP; the voice assistant can start, navigate, and answer quizzes hands-free.

📄
Syllabus Manager

Upload PDF syllabi and course documents. The system extracts text content and builds an interactive knowledge graph showing topic proficiency. Users can mark topics as mastered, which updates the visual progress graph. Supports multiple documents per user.

🧠
Topic Resolver
AI

Ask any study question and get a full AI-powered explanation with:

  • Detailed concept breakdown (Gemini)
  • Related YouTube video suggestions
  • Auto-generated concept diagrams / mind maps
  • XP awarded for learning sessions
📷
Photo Solver
AI

Take a photo of any handwritten problem, printed question, or diagram and get an instant AI solution. After solving, automatically generates a follow-up quiz based on the same topic to reinforce learning. XP awarded on correct answers.

📊
Progress Tracker

Comprehensive analytics dashboard showing:

  • XP growth chart over time
  • Weekly habit matrix (tick off habits per day)
  • Streak calendar visualization
  • Completed tasks over time
  • Study session hours breakdown
👥
Friends & Social

Full social graph system. Search users by name, send/accept/reject friend requests. View friend profiles with their XP, level, rank, task count, and public bio. Real-time online/offline presence indicator on the dashboard.

🔴
Live Streams
LIVE

Stream your Pomodoro study session live directly from Focus Mode. Other users can watch, see the topic and subject being studied, and view the streamer's live timer. Study history and past streams are archived for replay.

⚔️
Byte Battle

Real-time 1v1 or group competitive quiz battle using Socket.IO WebSockets. Create or join a room with a code, answer AI-generated questions in real time, vote on answers, and win XP based on performance. Built on Socket.IO for instant synchronization between players.

🤖
AI Coach
AI

Persistent Gemini AI chat tutor that remembers the conversation context within a session. Ask study questions, request explanations, get motivation, or discuss any academic topic. Message history is saved per user.

🛒
Item Shop

Spend earned XP on cosmetic upgrades:

  • Themes: Neon City, Sakura, Cyberpunk, Synthwave, Aurora
  • Avatar Frames: Golden, Diamond, Fire, Ice, Glitch
  • Equipped items apply instantly across the entire app UI
  • Purchase history tracked per user
🏆
Leaderboard

Global XP-based leaderboard ranking all users by level and total XP. Shows user avatar, rank badge, streak, and level. Your own rank is highlighted. Verse can speak your rank and the top 5 players aloud on voice command.

🎫
Support Center

Full ticket-based support system. Users create tickets with categories (General / Bug / Inappropriate / Help), and the admin responds directly via the admin panel. Unread message badges and real-time status tracking (Open → In Progress → Closed).

💬
Group Chat (Study Guilds)

Create or join study groups via invite code. Features admin controls (kick, rename, delete group, regenerate invite code), message pinning for announcements, file/image sharing, and a shared whiteboard canvas for collaborative diagrams.

🧘
Zen Mode

Distraction-free full-screen focus interface. Hides all navigation and UI elements so users can concentrate purely on their work. Toggled instantly via the sidebar or by voice command ("Zen mode").

🎁
Invite & Earn

Unique referral system — each user gets a personal invite link. When someone joins using that link, both users receive a bonus XP reward. Dashboard shows referral count and total XP earned through referrals.

📅
Calendar & Events

Personal event calendar with due-date warnings. Create events with dates and times. The system checks for upcoming deadlines and surfaces warning banners. Dashboard shows upcoming event count and Verse can report events on voice command.

📱
Progressive Web App
PWA

Fully installable as a native app on Android and iOS — no app store needed. Service Worker caches assets for offline use. Auto-install prompt appears for new users. Works seamlessly on desktop and mobile with responsive layouts.

🎙️ Verse — AI Voice Assistant
Natural Language Full-UI Control Engine · Powered by Google Gemini
Verse is StudyVerse's built-in voice assistant that goes far beyond simple navigation. It understands natural, casual speech and can control every UI element in the app — clicking buttons, typing text, selecting options, and even drawing on the whiteboard — all via voice. It reads live user data (XP, streak, tasks, friends, leaderboard rank) and speaks responses aloud using the browser's Text-to-Speech engine. Backed by Gemini AI, it understands slang, context, and intent — not just rigid commands.
